<h1 id="intro_new">Introduction to Braille</h1>

<h2 id="basics_new">The Basics</h2>

<p>First, think of braille as the same alphabet that we use in English, but made for touch reading. Braille works by creating tactile shapes the blind can learn to read by touch. Each braille character, or <strong>cell</strong> is made of up to six dots in a two-by-three arrangement.</p>

<ul class="infostrip span2">
<li>[[br:0]][[capt:dot0]] blank cell (space)</li>
<li>[[br:1]][[capt:a]] one dot (letter a)</li>
<li>[[br:123456]][[capt:dot123456]] full cell (for)</li>
</ul>

<p>For reference, braille dots are numbered one to six, in two columns.</p>

<ul class="infostrip span2">
<li>[[br:1]] dot 1 </li>
<li>[[br:2]] dot 2 </li> 
<li>[[br:3]] dot 3 </li>
<li>[[br:4]] dot 4 </li>
<li>[[br:5]] dot 5 </li>
<li>[[br:6]] dot 6 </li>
<li>[[br:135]] dot 135 </li>
</ul>

<h2 id="numbers_new">Numbers</h2>

<p>Basic numbers are written by using the number symbol, [[capt:dot3456]] which converts letters [[br:1]] A (for 1) through [[br:245]] J (for 0). The number prefix starts the number format, then things return to letters after a space. Texts with lots of math are usually written in a specialized braille code called Nemeth Braille.</p>

<h2 id="formatting_new">Formatting and styling</h2>

<p>Capital and italic letters are created using special characters along with the letters described above.</p>

<h3 id="capitals_new">Capitals</h3>

<p>A [[br:6]] capital sign signals that an uppercase character is next. Use it once for an initial cap, twice to capitalize the whole word. Three starts an all caps passage of two or more words. To end the passage, use two capital signs and you're back to lowercase.</p>

<ul class="infostrip">
<li>[[br:6]][[capt:dot6]] Capital Symbol</li>
<li>[[br:6 14 1 1234]][[capt:dot6 c a p]] Cap</li>
<li>[[br:6 6 2456 135 1235 145]][[capt:dot6 dot6 w o r d]] WORD</li>
</ul>

<h3 id="italics_new">Italics</h3>

<p>Italics employ the [[br:46]] italic symbol followed by a second character to indicate how much following text will be italicized.</p>

<ul class="infostrip">
<li>[[br:46 23]][[capt:dot46 dot23]] italic letter</li>
<li>[[br:46 2]][[capt:dot46 dot2]] italic word</li>
<li>[[br:46 2356]][[capt:dot46 dot2356]] begin passage</li>
<li>[[br:46 3]][[capt:dot46 dot3]] end passage</li>
</ul>
